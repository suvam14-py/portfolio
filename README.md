# Suvam Behera — motion portfolio

## Run locally
1. Extract this ZIP.
2. Open the extracted `suvam-portfolio-horizontal-scroll` folder in VS Code.
3. Install/enable Live Server if needed, then open `index.html` with **Go Live**.
4. For the GSAP-powered motion, keep an internet connection while viewing the page (GSAP is loaded from jsDelivr). The page has a native fallback if the CDN is unavailable.

## Included interactions
- Cinematic hero entrance and section reveal animations
- Scroll progress line and subtle pointer interaction on desktop
- Scroll-controlled horizontal Selected Work gallery on desktop
- Full-screen project case study overlay with keyboard and next/previous navigation
- Reduced-motion support and responsive mobile layout

## Personal assets
This ZIP does not contain your private `images/camera-logo.png` or `resume.pdf` files. To restore them, copy your `images` folder and `resume.pdf` from your existing portfolio into this project folder. The email link in `index.html` is still a placeholder (`YOUR_EMAIL@example.com`); replace it with your real email before publishing.
